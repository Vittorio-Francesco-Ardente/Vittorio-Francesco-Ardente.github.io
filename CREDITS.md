**Provenance notes.**
- `vfa-code` is the site author's own work, generated in this project (an HTML render of the site's sample SQL query in an editor, 1440×960).
- The other fifteen photographs were extracted from the source packages of archive.ubuntu.com (`ubuntu-wallpapers`, `budgie-wallpapers`, `xubuntu-community-artwork`, `ubuntu-mate-artwork`). Author and licence come from each package's `debian/copyright`; where it names the original page (StockSnap, Skitterphoto, a wallpaper-contest thread) it is linked above. Photos in `ubuntu-wallpapers` without a dedicated entry fall under the package's general licence, CC BY-SA 3.0, with the author taken from the file name. The Ubuntu MATE image (`castelluccio`) was cropped below the logo overlaid on the original wallpaper. The Alpe di Siusi location comes from the photograph's own description; `wisla` is the author's title (“Wisla”), the exact viewpoint is not stated.
- **Removed in this pass because the licence was not clear:** `guitar-body` (“12Cordas”, gill santos) and a bicycle-chain photo by Aniruddha Kibey. The Ubuntu Budgie package assumes CC BY-SA 4.0 from the rules of its Flickr contest group, but the photographers' own Flickr pages show “All rights reserved”. `colosseum`, `tatry` (384×288, too small for retina screens) and `forest-road` (generic) were replaced by more personal subjects and are no longer distributed.
- **Not represented: tractors / agricultural machinery.** No photograph of a tractor with a documented reusable licence was reachable from the build environment (Wikimedia Commons, Unsplash, Pexels, Flickr, the Library of Congress and Openverse were blocked; the Ubuntu, Debian and GitHub artwork collections that were reachable contain none). Agriculture is represented by the ploughed field, the wheat, the windmills and Castelluccio. The right source for a tractor is a photograph of Vittorio's own: add it with `scripts/passion-images.mjs` as described in the README.
